1 · Request Pipeline (POST /chat)

Client / Browser

graph-frontend (Vite dev server :5173). Hash router: #/ landing, #/app workspace, #/demo/* mock pages (in-memory only).

▶

Vite Dev Proxy

  • Forwards /chat /sessions /health /providers to :3000
  • Strips browser Origin header (fail-closed CORS)
  • Injects Authorization: Bearer GATEWAY_API_TOKEN
▶

Gateway Edge (server.js)

  • Bearer token check — timing-safe compare
  • Fail-closed CORS: allowlist only, 403 otherwise
  • JSON body parsing, error mapping 400/500
▼

Validation (routes/chat.js)

  • session_id: string, [A-Za-z0-9_-]{1,64}
  • message: required string
  • provider: optional string, must be known name (401-safe 400 otherwise)
  • Client-supplied url/model fields never reach adapters
▶

Memory Context Build

  • Latest checkpoint + trailing turns
  • Blocked turns excluded from prompts
  • 503 memory_unavailable on store failure
▼

Provider Chain + Failover

  • Enabled = env key present: openai → gemini → claude → nvidia → openai_compat
  • Per-provider timeout PROVIDER_TIMEOUT_MS (default 30 s)
  • Request budget REQUEST_DEADLINE_MS (default 60 s) — shared across the chain; budget spent → stop, 504 "request deadline exceeded"
  • Failover on rate_limit / provider_error / auth_error / timeout; preferred provider tried first via "provider": "nvidia"
  • Late settlement never breaks the response
▶

Memory Write

  • Every turn appended as a node linked by prev_id
  • Records provider, failed_providers[], status
  • Auto-checkpoint every 5 turns
  • Write failure → still 200 + X-Memory-Saved: false
▶

Storage Backend

  • File store: data/sessions/*.json (default)
  • Postgres/Supabase via DATABASE_URL (db/schema.sql, npm run migrate)
  • REQUIRE_DATABASE=true guard: refuses to start without DATABASE_URL
implemented + tested partial / pending verification
